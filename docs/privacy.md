# Dayglance privacy policy

Last updated: October 24, 2026

Dayglance is a schedule widget for Windows made by Acidminded. This policy covers the Microsoft Store version and the version downloaded from GitHub.

## What Dayglance stores

Dayglance saves your activities, notes, reminder and completion history, custom themes and preferences in a file on your PC:

- Microsoft Store version: inside the app's own data folder, `%LOCALAPPDATA%\Packages\<Dayglance package>\`. Windows deletes this folder when you uninstall Dayglance.
- GitHub version: `%LOCALAPPDATA%\Dayglance`.

This data never leaves your PC unless you choose to export it with **Settings → Data & updates → Export…**, in which case it goes only to the file you pick.

## What Dayglance sends

- **Microsoft Store version:** nothing. It makes no network requests. Updates come through the Microsoft Store.
- **GitHub version:** only an optional update check, which asks GitHub (api.github.com) for the latest Dayglance release. The request carries no schedule data or personal information; GitHub receives your IP address and the app version as with any web request. You can turn the check off in **Settings → Data & updates**.

Dayglance has no accounts, ads, analytics, telemetry or crash reporting. If Dayglance hits an error, it writes a `crash.log` next to your schedule on your PC and shows you where it is; nothing is sent.

## Children

Dayglance does not collect personal information from anyone, including children.

## Changes and contact

If this policy changes, the new version is posted on this page with a new date. Questions: open an issue at <https://github.com/acidminded95/dayglance/issues>.
